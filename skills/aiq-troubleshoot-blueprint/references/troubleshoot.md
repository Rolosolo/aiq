# Troubleshooting Reference

| Symptom | Route |
|---|---|
| Install/import failure | `aiq-setup-environment` |
| API/UI/Compose/Helm down | `aiq-deploy-blueprint` |
| Research output missing citations | `aiq-run-research` or `aiq-configure-tools` |
| Async job stuck/failed | `aiq-manage-jobs` |
| Model/prompt/routing issue | `aiq-configure-agents` |
| Tool/provider unavailable | `aiq-configure-tools` |
| Knowledge retrieval empty | `aiq-manage-knowledge` |
| Benchmark fails | `aiq-evaluate-benchmarks` |
| Trace parse/report fails | `aiq-analyze-tokenomics` |

Collect minimal read-only evidence first. Redact secrets and sensitive prompts.
