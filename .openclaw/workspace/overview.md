# AIQ OpenClaw Overview

The AI-Q Blueprint contains:

- AIQ agents under `src/aiq_agent/`.
- Workflow configs under `configs/`.
- API, CLI, debug, UI, and benchmark frontends under `frontends/`.
- Tool/source integrations under `sources/`.
- Docker Compose and Helm assets under `deploy/`.
- Documentation under `docs/source/`.
- Focused agent skills under `skills/`.
- Existing packaged local-server helper under `.agents/skills/aiq-research/`.

Use `skills/README.md` as the preview catalog.
